# 版校档案 · ProofArchive

本地栅格版面校样档案。以页面、不可变像素版本、物理成品尺寸和区域审校记录组织工作，面向设计稿修改校对与印前留档。所有示范由程序合成，不代表实际印刷观测。

运行 `bash start.sh`，打开 http://127.0.0.1:8913 ，点击“装载合成校样”。页面可导入 PNG/JPEG/单页TIFF，新增当前页版次、编辑成品尺寸和声明出血、调整页序、复制页、裁切旋转生成新校样、记录批注和审校意见、比较版次差分、检查分辨率/出血/批注/简化墨量、生成联系样张、按成品尺寸生成大幅展板的分张校样打印，以及下载档案包和审校报告。快照保存与恢复档案编辑状态，像素资源不可变。

### 分张校样打印

“分张校样打印”把当前版次按其声明的成品物理尺寸（mm）铺到选定纸张的可打印区域，用于办公室打印机分张输出后拼墙核对实际尺寸。可设置纸张（A5/A4/A3/Letter/Legal/Tabloid 或自定义）、横竖方向（自动按版面比例选择）、四边留白、相邻纸张重叠和打印 DPI（72–300）。对话框先返回分张计划与整张覆盖关系预览：行列网格、品红/青色重叠带、每张 R 行 C 列编号与物理坐标，末行/末列只剩窄条时红框标注，窄条保持原比例不拉伸、不漏内容，并给出放大、窄条、小留白、重叠过大等提示；纸张放不下有效内容、重叠过大或像素/张数超限时在生成前直接报错。

每张分张图为同一 1:1 物理比例（PNG 内嵌 DPI），页号与可区分的接缝配准十字、虚线对位线、成品裁切角线、物理坐标标尺只画在纸张留白、重叠带或末尾空白，不遮挡最终保留内容。可逐张下载，也可下载整包 ZIP：全部分张 PNG、覆盖总览、`manifest.json`/`manifest.csv` 清单（含行列顺序、每张覆盖的板面物理坐标、重叠宽度与 SHA256）和 `assembly.txt` 拼回说明。分张为临时打印输出，不创建新版次、不修改原始像素与档案修订号；联系样张与原始版次下载路径不受影响。护栏：最多 48 张，单张 2400 万像素、整板 1.2 亿像素。

`图像准备工具`提供自有通用图像准备引擎：照片序列导入、配准、融合、去噪、后期调整、遮罩、局部处理、诊断和图像输出。需要处理的照片可在该工具导出后导入版校档案。该底层从自有 ScanWeave 图像引擎复用，主档案业务由独立 proofarchive 包实现。两个工作区持久数据独立。

## 启动与数据

Docker 使用已锁定第三方运行环境，`bash start.sh`（本地已有 `solo12-scanweave:1.0` 第三方缓存镜像；经典构建器复用该镜像，避免远端解析）。容器项目与卷为 `solo13-proofarchive`，仅监听本机8913，卷挂载 `/data`，`docker compose down` 保留数据。Python 3.11/3.12 可直接安装 requirements.txt 并运行 app.py；设置 PROOFARCHIVE_DATA_DIR 与 PORT 更改目录和端口。

单图最大48MiB，每边16–6000像素，总计1600万像素；每档案200页，每版200批注，30个快照。ZIP压缩输入192MiB、展开384MiB。当前为同步小型本地工具，CPU2核/内存2GiB；已验证示范640×900，不承诺极限容量性能。联系表限制2400万像素。

比较按像素居中或左上角放置，不自动配准或缩放。差分按纸白合成透明度。出血为人工声明，不推断图案延伸。CMYK为sRGB互补模型及可调黑版生成，非ICC印刷分色，不包含专色、字体、叠印或PDF解析。色彩导入支持嵌入ICC转换，输出PNG为8位RGBA。裁切采用实际整数像素边界，批注按同一边界转换。

档案包保留全部页面版次、批注、物理规格和审校记录，并校验资源SHA256；导入创建新的页面/版次身份，不覆盖旧档案。快照不打包，审校报告为JSON。原始文件压缩字节与非像素元数据不完整保留。

## 源码

proofarchive/store.py 管理独立档案与快照，catalog.py 管理页和版次，images.py 处理色彩、透明及图像资源，geometry.py 变换图像与批注，compare.py 进行像素差分，annotations.py 管理区域审校，preflight.py 进行物理预检，separations.py 生成软分色，layout.py 生成联系样张，tiling.py 计算分张几何并渲染带标记的分张校样与清单，packages.py 负责档案包，api.py 接通页面。
