# 版校档案 · ProofArchive

本地栅格版面校样档案。以页面、不可变像素版本、物理成品尺寸和区域审校记录组织工作，面向设计稿修改校对与印前留档。所有示范由程序合成，不代表实际印刷观测。

运行 `bash start.sh`，打开 http://127.0.0.1:8913 ，点击“装载合成校样”。页面可导入 PNG/JPEG/单页TIFF，新增当前页版次、编辑成品尺寸和声明出血、调整页序、复制页、裁切旋转生成新校样、记录批注和审校意见、比较版次差分、检查分辨率/出血/批注/简化墨量、生成联系样张及下载档案包和审校报告。快照保存与恢复档案编辑状态，像素资源不可变。

## 批注连续审阅与审阅包

“批注连续审阅”按档案页序、再按版次内批注编号生成待解决队列，可勾选包含已解决项。选中一条时左侧清单高亮，主区同时显示橙色加粗框的整页定位图与带上下文留白的局部缩略图（横竖图、贴近边缘的框都在画布外补白，保证批注框完整可辨）；可在该视图直接解决、重开或修改批注，解决后自动跳到下一条待办，也可上下条切换。

“审阅包 ↓”导出 ZIP：`review.json`（含页名、页序、版次名、批注编号、类型、原图归一化位置、批注内容、处理状态与审校意见，仅 resolved/review_note 两个字段允许同事修改）、`index.csv` 人工核对表，以及 `crops/` 内每条批注的局部缩略图。“导回审阅包”先预检再写回，逐条给出可核对结果：已更新、无需更新、重复导回、已跳过及原因。导回只按档案/页/版次/批注的稳定编号精确对应原批注，并复核原图位置一致；版次变化、页面或批注被删除、位置被改动、来自其它档案或包内重复条目一律跳过，绝不新建批注，也不会把结论套到其它位置。同一审阅包重复导回且内容未变时识别为重复、不改动修订号。普通页面批注框与旧档案包的导入导出、审校报告保持可用。

`图像准备工具`提供自有通用图像准备引擎：照片序列导入、配准、融合、去噪、后期调整、遮罩、局部处理、诊断和图像输出。需要处理的照片可在该工具导出后导入版校档案。该底层从自有 ScanWeave 图像引擎复用，主档案业务由独立 proofarchive 包实现。两个工作区持久数据独立。

## 启动与数据

Docker 使用已锁定第三方运行环境，`bash start.sh`（本地已有 `solo12-scanweave:1.0` 第三方缓存镜像；经典构建器复用该镜像，避免远端解析）。容器项目与卷为 `solo13-proofarchive`，仅监听本机8913，卷挂载 `/data`，`docker compose down` 保留数据。Python 3.11/3.12 可直接安装 requirements.txt 并运行 app.py；设置 PROOFARCHIVE_DATA_DIR 与 PORT 更改目录和端口。

单图最大48MiB，每边16–6000像素，总计1600万像素；每档案200页，每版200批注，30个快照。ZIP压缩输入192MiB、展开384MiB。当前为同步小型本地工具，CPU2核/内存2GiB；已验证示范640×900，不承诺极限容量性能。联系表限制2400万像素。

比较按像素居中或左上角放置，不自动配准或缩放。差分按纸白合成透明度。出血为人工声明，不推断图案延伸。CMYK为sRGB互补模型及可调黑版生成，非ICC印刷分色，不包含专色、字体、叠印或PDF解析。色彩导入支持嵌入ICC转换，输出PNG为8位RGBA。裁切采用实际整数像素边界，批注按同一边界转换。

档案包保留全部页面版次、批注、物理规格和审校记录，并校验资源SHA256；导入创建新的页面/版次身份，不覆盖旧档案。快照不打包，审校报告为JSON。原始文件压缩字节与非像素元数据不完整保留。

## 源码

proofarchive/store.py 管理独立档案与快照，catalog.py 管理页和版次，images.py 处理色彩、透明及图像资源，geometry.py 变换图像与批注，compare.py 进行像素差分，annotations.py 管理区域审校，review.py 生成连续审阅队列、上下文局部图和审阅包导入导出，preflight.py 进行物理预检，separations.py 生成软分色，layout.py 生成联系样张，packages.py 负责档案包，api.py 接通页面。
