# 版校档案 · ProofArchive

本地栅格版面校样档案。以页面、不可变像素版本、物理成品尺寸和区域审校记录组织工作，面向设计稿修改校对与印前留档。所有示范由程序合成，不代表实际印刷观测。

运行 `bash start.sh`，打开 http://127.0.0.1:8913 ，点击“装载合成校样”。页面可导入 PNG/JPEG/单页TIFF，新增当前页版次、编辑成品尺寸和声明出血、调整页序、复制页、裁切旋转生成新校样、记录批注和审校意见、比较版次差分、按用途方案预检分辨率/四边出血/总墨量/批注、生成联系样张及下载档案包和审校报告。快照保存与恢复档案编辑状态，像素资源不可变。

预检用途方案按档案保存并分配给各页面，可配置有效分辨率、四边出血、总墨量阈值及各项问题严重程度（错误/警告/提示/关闭）；未配置方案的旧档案仍按默认要求（150 DPI、四边3mm、总墨量300%）检查。有效分辨率按像素与成品尺寸实测，不采用文件声明DPI，成品尺寸修改后重新判定。结果按页与问题类型汇总，列出实测值、采用的要求与通过原因。确需放行的问题可在具体版次记录带理由的例外，报告保留原问题与例外，新版次不自动沿用。页面查看与下载的审校报告来自同一次检查批次，检查不改动审校批准状态。

`图像准备工具`提供自有通用图像准备引擎：照片序列导入、配准、融合、去噪、后期调整、遮罩、局部处理、诊断和图像输出。需要处理的照片可在该工具导出后导入版校档案。该底层从自有 ScanWeave 图像引擎复用，主档案业务由独立 proofarchive 包实现。两个工作区持久数据独立。

## 启动与数据

Docker 使用已锁定第三方运行环境，`bash start.sh`（本地已有 `solo12-scanweave:1.0` 第三方缓存镜像；经典构建器复用该镜像，避免远端解析）。容器项目与卷为 `solo13-proofarchive`，仅监听本机8913，卷挂载 `/data`，`docker compose down` 保留数据。Python 3.11/3.12 可直接安装 requirements.txt 并运行 app.py；设置 PROOFARCHIVE_DATA_DIR 与 PORT 更改目录和端口。

单图最大48MiB，每边16–6000像素，总计1600万像素；每档案200页，每版200批注，30个快照。ZIP压缩输入192MiB、展开384MiB。当前为同步小型本地工具，CPU2核/内存2GiB；已验证示范640×900，不承诺极限容量性能。联系表限制2400万像素。

比较按像素居中或左上角放置，不自动配准或缩放。差分按纸白合成透明度。出血为人工声明，不推断图案延伸。CMYK为sRGB互补模型及可调黑版生成，非ICC印刷分色，不包含专色、字体、叠印或PDF解析。色彩导入支持嵌入ICC转换，输出PNG为8位RGBA。裁切采用实际整数像素边界，批注按同一边界转换。

档案包保留全部页面版次、批注、物理规格、用途方案和审校记录，并校验资源SHA256；导入创建新的页面/版次身份，不覆盖旧档案，放行例外不随新身份沿用。快照不打包，审校报告为JSON。原始文件压缩字节与非像素元数据不完整保留。

## 源码

proofarchive/store.py 管理独立档案、快照与预检批次，catalog.py 管理页和版次，images.py 处理色彩、透明及图像资源，geometry.py 变换图像与批注，compare.py 进行像素差分，annotations.py 管理区域审校，preflight.py 进行物理预检，profiles.py 管理用途方案与放行例外，separations.py 生成软分色，layout.py 生成联系样张，packages.py 负责档案包，api.py 接通页面。
